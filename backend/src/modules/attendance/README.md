# Attendance Module

## Purpose
Faculty roll-call capture, student safe-bunk calculation, biometric/ERP synchronization, and leave/On-Duty (OD) approval workflows.

## Future Responsibility
- Fast faculty attendance marking (Present, Absent, On-Duty, Late)
- Automatic percentage calculation with 75% regulatory warning thresholds
- Predictive safe-bunk formula: `Safe Bunks = floor((Present - (0.75 * Total)) / 0.75)`
- Student medical & event OD application and faculty approval workflow

## Dependencies
- Academics Module, Users Module, Notifications Module
