# Integrations Module

## Purpose
Bi-directional connectors for legacy college ERPs, biometric hardware, SIS systems, and Google Classroom/Moodle.

## Future Responsibility
- Periodic or webhook-based attendance & marks synchronization
- Student registry import (CSV, API, LDAP)
- Fault-tolerant retry queues with idempotency keys

## Dependencies
- Academics Module, Attendance Module, Jobs Queue
