# Social Module

## Purpose
Campus-exclusive social feed with verified student/faculty identities, anonymous posting guardrails, upvoting, threading, and academic note sharing.

## Future Responsibility
- Post publishing with categories (General, Academic, Lost & Found, Confessions, Event)
- Cryptographic anonymity tokenization to preserve privacy while enabling anti-abuse moderation
- Upvote/Downvote algorithms and comment threading
- Real-time post moderation and report flags

## Dependencies
- Users Module, Cache Service, Event Bus, Notifications Module
